Este sera un MMO espacial, naceras en el sistema solar planeta tierra
alli podras recolectar recursos, venderlos y comprarte una nave espacial 
con la nave espacial podras ir a otros planetas del sistema solar en busqueda de mejores recursos

Prototipo base inicial para navegador creado con HTML, CSS y JavaScript.
Abrir index.html directamente o iniciar un servidor local con:
python -m http.server 8000
Luego ir a http://localhost:8000
